Setup Guide v1.0

PW Lecture Downloader

Download PW lectures with audio and full seeking support — using a browser extension and a lightweight Android app.

How it works

This setup has two parts that work together:

  1. 1 Lemur Browser — plays the PW video and captures the DRM keys + stream URL, then generates a download command.
  2. 2 Video Downloader App — takes that command and saves the video to your phone.

Set up Lemur Browser

  1. 01Install Lemur Browser from the Play Store link above.
  2. 02Download the WidevineProxy2 ZIP. Do not extract it.
  3. 03Open Lemur and go to chrome://extensions/
  4. 04Turn Developer mode ON (top-right).
  5. 05Tap Load *.zip/*.crx/*.user.js file and select the downloaded ZIP.
  6. 06Open the extension → Choose File → select the .wvd file.
  7. 07
    In Command options → Additional arguments, paste:
    --append-url-params --save-dir /sdcard/Movies/PW_Downloads

A red Errors badge in the extension is normal on Lemur and can be ignored as long as keys are being captured.

2

Install the Video Downloader App

Download and install the APK from the Downloads section above.

If prompted, allow Install from Unknown Sources in your phone settings.

Download your first lecture

  1. 01In Lemur, open the PW website and play the lecture.
  2. 02Open the WidevineProxy2 extension and copy the full command from the Cmd section.
  3. 03Open the Video Downloader app.
  4. 04Paste the command into the input box.
  5. 05Tap Download and wait for it to finish.
  6. 06Your video is saved to /sdcard/Movies/PW_Downloads and appears in your Gallery.

The app can't extract keys on its own — it only downloads. Always generate a fresh command from Lemur right before pasting.

Troubleshooting

  • 403 Forbidden — the link expired. Refresh the video in Lemur and copy a new command.
  • No audio — make sure the command includes the --key line and matches the current video.
  • Can't seek — the app saves as MP4; try a different player (e.g. VLC or MX Player).
  • Permission denied — grant Storage permission to the app in Settings → Apps.
  • APK won't install — enable "Install from Unknown Sources" or install via your file manager.
  • Video not detected — copy a fresh command from Lemur and paste it again in the app.

Good to know

  • Keep both apps open while downloading — one generates the command, the other runs it.
  • Sign in to PW inside Lemur Browser first.
  • You can queue multiple lectures by repeating the copy-and-paste step.
  • Downloads land in /sdcard/Movies/PW_Downloads.
